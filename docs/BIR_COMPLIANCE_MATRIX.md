# BIR Compliance Matrix

This file is the accreditation evidence pack. Each requirement maps to its module, table, function and test.

Status key: `planned` → `partial` (some of it built and tested) → `tested` → `demo-ready`.
Test files: **core** = `packages/core/test/core.test.ts`, **p2** = `packages/core/test/phase2.test.ts`, **prop** = `packages/core/test/property.test.ts` (fast-check, 150 random business days per property, including random senior and group shares), **golden** = `packages/core/test/golden.test.ts` (files in `packages/core/test/golden/`), **dur** = `packages/storage-node/test/durability.test.ts` (real child processes on a real database file). The test name starts with the test ID.

Run everything: `npm test` (63 tests). Compliance core under evaluation: **`core 0.2.0`** (pre-accreditation).

Sources are as cited in the kickoff brief and **still to be verified** (see OPEN_QUESTIONS.md). Annex F will be cross-mapped once the RDO supplies it (Q7).

**Sample documents** for the TWG are generated by the golden tests and cover every document type at 58mm, 80mm and A4:
- `day-80mm.txt` and `day-58mm.txt`: a full restaurant day of invoices, voids, refunds, returns, supplementary documents, a manual invoice record, and X and Z readings;
- `invoice-sc-a4.html`;
- `invoice-sc-reprint-80mm.txt`;
- `invoice-nonvat-80mm.txt`, `invoice-exempt-80mm.txt` and `invoice-demo-58mm.txt`.

The seal is masked in these files because test keys are random.

## Findings worth showing the TWG

- **Phase 1:** the concurrency test found that `verifyAll` could raise a false integrity break while another process was writing. It now reads one SQLite snapshot.
- **Phase 2:** totals print in the order they are computed: Total sales, then VAT exemption, then discounts, then Amount due. A reader can follow the senior-citizen arithmetic line by line.
- **Phase 2:** group shares are prorated cumulatively, so the parts always add up to the line exactly. For example, ₱100.01 shared by four diners gives 25.00 and 25.01, never a lost or invented centavo.
- **Clock control:** issuing is refused when the device clock is more than 5 seconds behind the last document; smaller drift is logged.
